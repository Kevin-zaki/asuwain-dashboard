# Panti Asuhan Asuwain Timor — Landing Page (Next.js)

Tampilan landing page saja (tanpa backend/fungsi lain).

## Jalankan
```bash
npm install
npm run dev     # http://localhost:3000
npm run build && npm start
```

## Struktur
- `app/` — layout & halaman (TypeScript)
- `components/` — TopBar, Navbar, Hero, About, Channels, Wishlist, DonationForm, Gallery, Legal, Footer (TSX)
- `data/content.js` — seluruh teks/data (JavaScript)
- `styles/globals.css` — seluruh styling
- `public/images/` — foto dipotong dari desain (resolusi rendah); ganti dengan foto asli ber-nama sama
